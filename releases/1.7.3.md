# Ishtirak 1.7.3 (16 November 2026)

- **Much fewer requests:** Opening the app now makes 3 requests to the server instead of 13, and Home loads in a single request. Each one skips the extra access checks the old requests went through, so the app stays quick on a weak connection or a busy server.
- **No more flashing:** Home no longer flashes or jumps back to the top when it updates itself in the background. If nothing changed, it does not redraw at all.
- **Opens before signing in again:** The app shows your last Home at once, even while your sign-in is being renewed in the background.
